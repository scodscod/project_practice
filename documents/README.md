## ВВЕДЕНИЕ

В рамках проектной практики стояла задача создать с нуля Telegram-бота, который помогает пользователю находить синонимы и антонимы к словам русского языка. Итоговый продукт должен был быть не только рабочим, но и готовым к реальному использованию: запущенным на облачном хостинге и доступным для проверки.

Практика проходила в период с 03 февраля 2025 г. по 24 мая 2025 г. под руководством куратора от кафедры «Информатика и информационные технологии».

## 1. ОБЩАЯ ИНФОРМАЦИЯ О ПРОЕКТЕ

### 1.1. Название проекта

**«СинАнт Бот»** — Telegram-бот для подбора синонимов и антонимов русского языка.

### 1.2. Цели и задачи проекта

**Цель проекта:**
Разработать простого и полезного Telegram-бота, который позволяет пользователю быстро получить синонимы и антонимы к нужному слову, а также разместить бота на облачном сервере для круглосуточной работы.

**Задачи проекта:**
- изучить существующие лингвистические боты и сервисы для работы с русским языком;
- определить набор функций: поиск синонимов, поиск антонимов, отображение списка доступных слов, вывод случайного слова;
- спроектировать логику взаимодействия пользователя с ботом;
- реализовать бота на языке Python с использованием библиотеки aiogram;
- создать и наполнить словарную базу в формате JSON;
- обеспечить безопасное хранение токена вне системы контроля версий;
- освоить инструменты Git и Markdown для оформления репозитория;
- выполнить деплой бота на облачную платформу Render;
- подготовить итоговый отчёт.

### Приложение 1. Полный листинг файла `bot.py`

```python
import json
import os
import asyncio
import random
from aiogram import Bot, Dispatcher, types
from aiogram.filters import Command
from aiogram.types import ReplyKeyboardMarkup, KeyboardButton
from dotenv import load_dotenv

load_dotenv()

BOT_TOKEN = os.getenv('BOT_TOKEN')

bot = Bot(token=BOT_TOKEN)
dp = Dispatcher()

def load_synonyms():
    with open('data/synonyms.json', 'r', encoding='utf-8') as f:
        return json.load(f)

synonyms_db = load_synonyms()

main_keyboard = ReplyKeyboardMarkup(
    keyboard=[
        [KeyboardButton(text="Случайное слово")],
        [KeyboardButton(text="Список доступных слов")],
        [KeyboardButton(text="Помощь")]
    ],
    resize_keyboard=True
)

@dp.message(Command("start"))
async def cmd_start(message: types.Message):
    await message.answer(
        "Привет! Я бот-синонимайзер русского языка.\n\n"
        "Отправь мне слово — найду синонимы и антонимы.\n"
        "Используй кнопки ниже для навигации.",
        reply_markup=main_keyboard
    )

@dp.message()
async def handle_message(message: types.Message):
    user_input = message.text.lower().strip()
    
    if user_input == "случайное слово":
        word = random.choice(list(synonyms_db.keys()))
        data = synonyms_db[word]
        syn = " • ".join(data["synonyms"])
        ant = " • ".join(data["antonyms"])
        await message.answer(
            f"<b>Слово:</b> {word.upper()}\n"
            f"<b>Синонимы:</b>\n{syn}\n\n"
            f"<b>Антонимы:</b>\n{ant}",
            parse_mode="HTML"
        )
    
    elif user_input == "список доступных слов":
        words = ", ".join(sorted(synonyms_db.keys()))
        await message.answer(f"Слова в базе:\n\n{words}")
    
    elif user_input == "помощь":
        await message.answer(
            "Напиши слово, например: <b>красивый</b>, <b>умный</b>, <b>большой</b>",
            parse_mode="HTML"
        )
    
    elif user_input in synonyms_db:
        data = synonyms_db[user_input]
        syn = " • ".join(data["synonyms"])
        ant = " • ".join(data["antonyms"])
        await message.answer(
            f"<b>Слово:</b> {user_input.upper()}\n"
            f"<b>Синонимы:</b>\n{syn}\n\n"
            f"<b>Антонимы:</b>\n{ant}",
            parse_mode="HTML"
        )
    
    else:
        await message.answer(
            f"Слово '<b>{user_input}</b>' не найдено :(\n"
            f"Напишите /start и посмотрите список доступных слов.",
            parse_mode="HTML"
        )

async def main():
    print(f"Бот запущен! Слов в базе: {len(synonyms_db)}")
    await dp.start_polling(bot)

if __name__ == "__main__":
    asyncio.run(main())
```
